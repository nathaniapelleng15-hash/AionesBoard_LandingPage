# aionesboard

Landing page pengolahan dokumen untuk BUMD.

## Menjalankan secara lokal

1. Pasang dependensi dengan `npm install`.
2. Jalankan `npm run dev`.

Formulir demo menyiapkan draf email ke tim aionesboard. Formulir belum mengirim data ke server.

## Pemeriksaan

- `npm run lint`
- `npm run build`
